## ◈ Projetos

### 01. Sistema de Agendamento Jurídico

<sub>PROJETO ACADÊMICO • C#</sub>

Sistema desenvolvido em equipe para gerenciamento de compromissos jurídicos.

**Principais funcionalidades:**

- Menu de navegação.
- Cadastro de advogados.
- Cadastro de clientes.
- Agendamento de compromissos.
- Consulta de horários disponíveis.
- Verificação de conflitos de horários para evitar agendamentos simultâneos para o mesmo advogado.

**Tecnologia utilizada:** C#.
