## ◈ Projetos

### 01. Sistema de Agendamento Jurídico

<sub>PROJETO ACADÊMICO • C#</sub>

Sistema Computacional de Gerenciamento de Agenda Jurídica, desenvolvido para o escritório **Gomides & Gomes – Advocacia e Consultoria Jurídica**.

O projeto tem como objetivo facilitar a organização e o gerenciamento de compromissos do escritório.

**Principais funcionalidades:**

- Menu interativo para utilização do sistema.
- Cadastro de advogados.
- Cadastro de clientes.
- Registro e consulta de compromissos.
- Verificação de disponibilidade de horários.
- Identificação de conflitos quando um advogado já possui outro compromisso no mesmo horário.
- Bloqueio de agendamentos conflitantes.

**Tecnologia utilizada:** C#.

### 02. Planilha de Controle de Vendas

<sub>PROJETO PRÁTICO • EXCEL</sub>

Planilha desenvolvida para auxiliar no controle e na organização de vendas.

**Objetivos do projeto:**

- Organizar informações comerciais.
- Facilitar o acompanhamento das vendas.
- Auxiliar no gerenciamento das informações.

**Ferramenta utilizada:** Microsoft Excel.
